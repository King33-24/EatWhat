## 2. 价值主张

### 2.1 一句话定位

> "市面上的工具都在帮你**多看**，EatWhat 帮你**看清自己看了什么**。"

### 2.2 差异化卖点

- **不推送**：反算法、反成瘾设计 —— 在所有产品都抢用户注意力的时代，"反推送"本身就是稀缺资源
- **不替你做决定**：只呈现、追问、邀请；用户始终保持主体性
- **可解释**：每个分析结论都有具体证据（视频引用），不是黑盒

### 2.3 与现有竞品的差异

| 类别 | 代表产品 | 区别 |
|---|---|---|
| 数字戒断类 | Forest, One Sec | 它们帮你"少看"，我们帮你"看清" |
| 认知评估类 | [TODO] | 它们偏心理测评，我们基于真实数字行为 |
| 信息聚合类 | RSS、即刻、Feedly | 它们帮你"多看新东西"，我们帮你"看见你忽略的视角" |
| 浏览历史类 | History Trends | 它们只统计 URL，我们做"为什么这样看"的解释 |

## 4. 推广路径

### 4.1 第一阶段：种子用户（0-3 个月）

1. **B 站知识区 KOL 合作**
   - 目标 UP 主：@老蒋巨靠谱、@回形针、@沈逸老师 等用户群匹配的知识区 UP
   - 形式：内容植入 / 联名功能 / 付费推广
2. **内容营销**：在小宇宙、即刻、得到发自传播文案，例：
   - "我用 EatWhat 发现自己 1 个月只看 AI 内容"
   - "原来我以为自己很多元，结果 EatWhat 告诉我..."
   - "一个'反推送'app 是怎么帮我夺回深度思考的"

### 4.2 第二阶段：扩散（3-12 个月）

## 5. 为什么我们能做（团队 + 技术 + 定位）

### 5.1 技术壁垒

- **OpenClaw + 搜索 API + DeepSeek 筛选** 在"对立观点检索"上目前没有成熟竞品
- **Skill 框架** 让产品逻辑高度可定制，对业务变化适应力强

## 6. 风险与应对

| 风险 | 应对策略 |
|---|---|
| DeepSeek API 成本失控 / 限流 | 充值预算控制 / 引入本地模型选项 |
| B 站反爬 / 政策变化 | 拓展多平台 / 转向用户主动上报 |
| 用户嫌"被监测"反感 | 强调本地化运行 + 数据所有权归用户 |
| 商业化与"反推送"理念冲突 | Freemium 模式只对"功能深度"收费，不对"基础认知健康"收费 |
| 评委质疑"是否真有市场" | 引用信息茧房相关研究文献 + 用户访谈数据（需提前做） |
| 评委质疑"用户为何付费" | 强调「认知健康」和「健身房」类比：用户为长期健康买单 |
